```powershell

powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start_a_mysql.ps1
.\.venv\Scripts\python.exe scripts/check_environment.py
```

應看到demo與test各一行PASS。若FAIL，記錄錯誤並停在此步。兩行PASS後：


看到 `Running on http://127.0.0.1:5010` 後保持終端機開著。用Edge或Chrome打開 **http://127.0.0.1:5010/login**，按 **Ctrl+F5** 載入新畫面。不要用Live Server預覽HTML，這個網站需要Flask與MySQL一起運作。

## 3. 網路恢復：可選人工檢查

正常操作不需要開開發工具。想測斷網時，可先預覽並勾確認，F12的Network將網路切Offline，再點送出。應顯示查詢／重試原送出面板，返回修改與另行送出暫時停用。恢復Online，點查詢；若查無結果，點「重試原本的送出」。應只產生一張訂單。不要在未知結果時清除瀏覽器儲存資料。

「後端已成功、但回應丟失」已另用真實Edge自動驗證：重新整理後找回原訂單，列表仍只有一張。人工Offline測的是請求送出前斷線，兩者情境不同。

